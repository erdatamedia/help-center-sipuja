# Mengelola Profil Saya

Menu Profil berfungsi sebagai pusat informasi akun Anda di portal SIPUJA untuk melihat detail data diri serta melakukan pembaruan informasi profil.

![Profil Saya](/images/profile.png)

---

## 1. Informasi Detail Akun

Pada halaman Profil Saya, Anda dapat melihat ringkasan informasi akun yang terdaftar:

* Informasi Utama: Menampilkan nama, alamat email, serta status keaktifan akun.
* Detail Akun: Menampilkan data lengkap seperti Nama Lengkap, Email, Jenis Kelamin, Tanggal Lahir, dan Tanggal Akun Dibuat.

---

## 2. Cara Mengubah Data Profil

![Upadate Profil](/images/update-profile.png)

Untuk memperbarui informasi data diri Anda:

1. Buka menu Profil pada sidebar sebelah kiri.
2. Klik ikon pensil (edit) yang terletak di pojok kanan atas kartu profil utama.
3. Form Edit Profil akan muncul di bagian atas. Anda dapat memperbarui:
   * Nama Lengkap
   * Jenis Kelamin
   * Tanggal Lahir
4. Setelah selesai mengubah data, klik tombol Simpan Perubahan. Jika ingin membatalkan, klik tombol Batal.

---

## 3. Fitur Tambahan di Sidebar

Pada bagian paling bawah menu navigasi (sidebar) sebelah kiri, terdapat dua fitur pendukung:

* Mode Malam (Dark Mode): Klik ikon bulan/matahari di pojok kiri bawah untuk mengubah tema tampilan antara terang dan gelap agar nyaman di mata.
* Logout (Keluar Akun): Klik tombol Logout di pojok kiri bawah saat ingin mengakhiri sesi dan keluar dari portal SIPUJA demi keamanan akun Anda.
