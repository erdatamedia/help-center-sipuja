# Mengenal SIPUJA

SIPUJA (Sistem Pengujian Hasil Lab) adalah platform publik yang dirancang untuk memudahkan masyarakat dalam mengakses informasi dan layanan Laboratorium Balai Perakitan dan Pengujian Ruminansia Besar secara daring.

Melalui halaman utama ini, Anda dapat melihat rincian informasi layanan pengujian, tarif, alur prosedur, hingga dokumen resmi laboratorium. Untuk mulai mengajukan permohonan pengujian, Anda dapat membuat akun baru terlebih dahulu melalui tombol Daftar dan langsung Masuk jika sudah memiliki akun di pojok kanan atas.

# Cara Mendaftar Akun SIPUJA

Sebelum dapat menggunakan layanan SIPUJA, pengguna perlu membuat akun terlebih dahulu.

1. Membuka Halaman Pendaftaran

Pada halaman utama SIPUJA, klik tombol **Daftar**.

![Tombol Daftar pada halaman utama SIPUJA](/images/langkah-pertama/tombol-daftar.jpeg)

Setelah itu, Anda akan diarahkan ke halaman formulir pendaftaran.

2. Mengisi Formulir Pendaftaran

Lengkapi data yang tersedia pada formulir pendaftaran, yaitu:

- Nama
- Email
- Password
- Konfirmasi Password
- Jenis Kelamin
- Tanggal Lahir
- Pendidikan Terakhir
- Pekerjaan

![Formulir pendaftaran akun SIPUJA](/images/langkah-pertama/formulir-daftar.jpeg)

3. Menyelesaikan Pendaftaran

Setelah seluruh data terisi dengan benar:

1. Periksa kembali data yang telah dimasukkan.
2. Pastikan password dan konfirmasi password sama.
3. Klik tombol **Daftar Sekarang**.
!![Tombol Daftar pada halaman utama SIPUJA](/images/langkah-pertama/klik-daftar.jpeg)
4. Tunggu hingga proses pendaftaran berhasil.

Setelah akun berhasil dibuat, Anda dapat melanjutkan ke halaman **Masuk**.

# Cara Masuk ke Akun SIPUJA

Setelah berhasil membuat akun, Anda dapat masuk ke SIPUJA menggunakan email dan password yang telah didaftarkan.

1. Membuka Halaman Masuk

## Mengisi Data Akun

Masukkan:

1. Email yang telah didaftarkan.
2. Password akun Anda.
3. Klik tombol **Masuk**.

!![Tombol Masuk pada halaman utama SIPUJA](/images/langkah-pertama/form-masuk.jpeg)

Jika email dan password yang dimasukkan benar, Anda akan diarahkan ke halaman dashboard SIPUJA.

> **Catatan:** Pengguna yang belum memiliki akun harus melakukan pendaftaran terlebih dahulu sebelum dapat masuk ke dalam sistem.

## Mengalami Kendala?

Jika Anda **lupa password** akun SIPUJA, Anda dapat mengajukan permintaan reset password melalui halaman masuk.

1. Mengajukan Reset Password

Pada halaman **Masuk**, klik **Lupa Password**.

![Tombol Lupa Password pada halaman masuk](/images/langkah-pertama/lupa-password.jpeg)

2. Masukkan email yang terdaftar pada akun SIPUJA, kemudian kirim permintaan reset password.

![Form pengajuan reset password](/images/langkah-pertama/reset-password.jpeg)

3. Menunggu Persetujuan Admin

Setelah permintaan dikirim, Anda akan diarahkan ke halaman **Menunggu Persetujuan Admin**.

![Halaman menunggu persetujuan admin](/images/langkah-pertama/menunggu-persetujuan.jpeg)

Pada halaman tersebut, sistem akan menampilkan informasi bahwa permintaan reset password Anda sedang menunggu persetujuan admin.

4. Mengecek Status Persetujuan

Untuk mengetahui status permintaan, klik tombol **Cek Status Persetujuan**.

Jika permintaan belum disetujui, sistem akan menampilkan pesan:

> **Permintaan masih menunggu persetujuan admin.**

Setelah permintaan disetujui, Anda dapat melanjutkan proses pengaturan password baru.
