# Langkah Pertama Menggunakan Aplikasi

Panduan ini bagi Anda yang baru pertama kali membuka aplikasi sipuja.

## 1. Masuk atau Buat Akun
![Login](/images/login.png)
Klik tombol **Masuk** di pojok kanan atas. Jika anda belum mempunyai akun Klik **Daftar** dan isi email Anda.

## 2. Lengkapi Profil

Setelah masuk, lengkapi nama dan foto profil Anda di menu **Pengaturan Akun**.

## 3. Jelajahi Menu Utama
![dashboard](/images/dashboard.png)
Menu utama ada di sisi kiri layar. Dari sana Anda bisa mengakses semua fitur.

Butuh bantuan lebih lanjut? Lihat [Panduan Fitur](/help/panduan-fitur/mengelola-akun) atau [FAQ](/help/faq).
