# Aplikasi Bermasalah? Coba Ini Dulu

Sebelum menghubungi support, coba langkah-langkah berikut.

## Halaman Tidak Bisa Dibuka

- Muat ulang (refresh) halaman.
- Pastikan koneksi internet Anda stabil.
- Coba buka di jendela penyamaran (incognito) untuk mengecek apakah masalah dari cache browser.

## Tidak Bisa Masuk (Login)

- Pastikan email dan kata sandi sudah benar.
- Klik **Lupa password?** di halaman login, lalu masukkan email akun Anda.

![Halaman login SIPUJA dengan link Lupa password](/images/troubleshooting/login-lupa-password.png)

- Reset password **tidak dilakukan otomatis** — admin akan memverifikasi permintaan Anda terlebih dahulu sebelum reset password diaktifkan. Jadi Anda tidak akan langsung menerima email/link reset setelah mengirim permintaan.

![Halaman lupa password yang menjelaskan proses verifikasi admin](/images/troubleshooting/lupa-password-verifikasi.png)

- Jika sudah menunggu cukup lama dan belum ada perubahan, hubungi tim support untuk mempercepat verifikasi.

## Kode Pembayaran (E-Billing) Belum Muncul

- Setelah permohonan dibuat dan sampel dinyatakan **"Verifikasi Sampel: OK"** di tab *Pengiriman & Verifikasi*, kode e-billing tidak langsung muncul secara otomatis.
- Pada tab **Pembayaran**, Anda akan melihat status **"Menunggu penerbitan e-billing dari admin"** — ini artinya admin belum menerbitkan kode billing untuk permohonan Anda.

![Tab Pembayaran menampilkan status menunggu penerbitan e-billing dari admin](/images/troubleshooting/pembayaran-menunggu-ebilling.png)

- Tidak perlu refresh berkali-kali; kode akan muncul begitu admin menerbitkannya. Jika sudah menunggu lebih dari beberapa hari kerja, hubungi tim support dengan menyertakan nomor permohonan Anda (contoh: `SIPUJA-2608-002`).

## Status Permohonan Tidak Berubah-Ubah

- Setiap perubahan status permohonan (Verifikasi, Menunggu Pembayaran, dll.) dilakukan **secara manual oleh admin**, bukan otomatis oleh sistem — jadi wajar bila ada jeda waktu antar tahap.
- Anda bisa memantau riwayat perubahan status secara lengkap di tab **Riwayat** pada halaman detail permohonan.

![Tab Riwayat menampilkan log perubahan status dengan tanggal dan waktu](/images/troubleshooting/riwayat-status.png)

- Anda juga akan mendapat catatan di halaman **Notifikasi** setiap kali status permohonan diperbarui.

## Masih Belum Berhasil?

Jika masalah masih berlanjut, silakan hubungi admin laboratorium untuk mendapatkan bantuan lebih lanjut.
